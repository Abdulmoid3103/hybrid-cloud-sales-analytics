**Cloud Sales Analytics Pipeline | Python, Pandas, SQLite, Streamlit, AWS Architecture**

Built a local sales analytics pipeline that validates and transforms CSV transactions using Python and Pandas, stores cleaned data in SQLite, and visualizes revenue, profit, margin, product and regional insights in an interactive Streamlit dashboard. Documented a future AWS serverless data-lake design using S3, Lambda, Glue and Athena; no cloud resources were deployed.
